# 🕊️ Comunidade Viva

Bem-vindo ao projeto **Comunidade Viva** — um painel digital moderno e acolhedor para organizar e apresentar informações da igreja, ministérios, membros, eventos e conteúdos pastorais de forma visual e intuitiva. 🌟

## ✨ O que é este projeto?

Este projeto é uma interface web estilosa e responsiva, pensada para funcionar como um verdadeiro centro de comunicação e gestão da vida da igreja. Com uma aparência elegante e dinâmica, ele reúne diferentes áreas como:

- 🏛️ Dashboard da igreja
- 👥 Gestão de membros
- 🎶 Ministérios de louvor
- 📸 Galeria de fotos
- 📚 Biblioteca e ensino bíblico
- 🩺 Saúde pastoral e acompanhamento
- 🕯️ Cultos, eventos e comunicação

## 🚀 Funcionalidades principais

- Interface moderna com visual limpo e profissional
- Navegação organizada por módulos
- Design responsivo para desktop e mobile
- Destaques para atividades, cultos e ministérios
- Experiência visual inspirada em uma comunidade viva e conectada

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Chart.js
- Lucide Icons

## ▶️ Como visualizar o projeto

1. Abra o arquivo [Index.html](Index.html) no navegador.
2. Explore os módulos disponíveis no painel.
3. Navegue pelas seções e descubra a experiência completa.

## 📁 Estrutura do projeto

- [Index.html](Index.html) — estrutura principal da interface
- [styles.css](styles.css) — estilos e personalização visual
- [script.js](script.js) — lógica e interatividade do painel

## 🌈 Destaque do projeto

Este projeto foi criado com foco em:

- facilitar a comunicação da igreja
- organizar informações importantes em um só lugar
- oferecer uma experiência bonita, acolhedora e funcional

## 💬 Observação

O projeto está em constante evolução e pode ser expandido com mais módulos, integração com banco de dados, autenticação administrativa e muito mais.
